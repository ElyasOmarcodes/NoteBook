# 🎚️ سمارټ سټوډیو (Smart Studio)
### د غږ هوښیار مدیریت او اتومات سیسټم

سمارټ سټوډیو یوه سپکه، خپلواکه او هوښیاره برنامه ده چې د یوه مسلکي ډیجیټل
سټوډیو میکسر په توګه کار کوي. دا د ژوندي میکروفون غږ له شاته میوزیک (BGM)
سره ترکیبوي.

**اصلي خصوصیت — هوښیار Auto-Ducking:** کله چې څوک میکروفون ته خبرې وکړي،
سیسټم پخپله او په نرمۍ سره شاته میوزیک ښکته کوي. د چوپتیا پر مهال میوزیک
بیرته پورته راځي.

---

## ✨ خصوصیتونه

| پینل | تشریح |
|------|-------|
| 🔌 **د وسایلو لارښوونه** | د میکروفون او سپیکر (بلوتوث/USB/AUX) ټاکنه + Hot-plug refresh |
| 🎵 **مدغم میوزیک پلیر** | د .mp3/.wav فایلونو اپلوډ، Play/Pause/Stop، د حجم کنټرول |
| ⚙️ **د اتومات تنظیمات** | حساسیت، لږ/اعظمي حجم، د Fade سرعت، د چوپتیا ځنډ (Hold Time) |
| 📊 **ژوندۍ څارنه** | د میکروفون ریښتیني-وخت VU Meter او د حالت ښودنه |

```bash

# ۲. اړین کتابتونونه نصب کړئ
pip install -r requirements.txt
```

بیا خپل براوزر کې دا پته خلاص کړئ:

## 🎛️ د کارولو لارښود

1. **وسایل وټاکئ** — په پینل A کې خپل میکروفون او سپیکر غوره کړئ. نوي وسایل
   (لکه بلوتوث سپیکر) د «🔄 وسایل تازه کړئ» تڼۍ په کلیک کولو پیژندل کیږي.
2. **میوزیک لوډ کړئ** — په پینل B کې «📂 د میوزیک فایل وټاکئ» کلیک کړئ، بیا
   «▶ غږول».
3. **حالت وټاکئ:**
   - **اتومات:** سیسټم پخپله غږ تشخیصوي او میوزیک کموي/زیاتوي.
   - **لاسي:** تاسو پخپله د «اصلي حجم» سلایډر سره میوزیک کنټرولوئ.
4. **تنظیمات سم کړئ** (اتومات حالت کې):
   - **حساسیت (Threshold):** څومره غږ پکار دی چې ducking پیل شي.
   - **لږترلږه حجم:** د خبرو پر مهال د میوزیک کچه.
   - **اعظمي حجم:** د چوپتیا پر مهال د میوزیک کچه.
   - **Fade-Down / Fade-Up:** د ښکته/پورته کیدو سرعت (ms).
   - **د چوپتیا ځنډ (Hold Time):** د خبرو په منځ کې د لنډې چوپتیا پر مهال
     میوزیک ژر پورته نشي.

## 🧠 د کار طریقه (Backend Algorithm)

انجن هر **۵۰ms** د میکروفون د سیګنال **RMS** اندازه کوي:

```
که (RMS > Threshold):           →  غږ شته  →  میوزیک ښکته (Fade-Down)
که نه او (چوپتیا ≥ Hold Time):  →  چوپتیا  →  میوزیک پورته (Fade-Up)
```

د حجم ټول بدلونونه د **linear ramp** له لارې نرم ترسره کیږي (د هر sample
لپاره) چې هیڅ ناڅاپي «کلیک» یا قطع ونه شي.

د **Flask-SocketIO** له لارې د VU meter او حالت معلومات سمدلاسه براوزر
ته لیږل کیږي (بې له page refresh).
